Blender Shader Manager
A lightweight Blender add-on (v5.1+) to save, organize, and instantly apply node-based shaders using JSON or ZIP files. It acts like a cassette system for your materials, allowing you to easily reuse them across projects.

Features
JSON & ZIP Export: Save node trees as lightweight JSON files, or pack them alongside their image textures into ZIP archives.

Full Node Support: Accurately saves and restores node links, custom properties, Color Ramps, and RGB Curves.

Category Management: Organize your shader library into custom subfolders directly from the UI.

Smart Import: Detects missing texture, value, or color inputs and prompts you for them when applying a saved shader.

Installation
Download the add-on as a .py file.

In Blender, navigate to Edit > Preferences > Add-ons.

Click the downward arrow in the top right, select Install from Disk..., and choose the downloaded file.

Check the box next to Material: Blender Shader Manager to enable it.

Usage
Open the 3D Viewport and press N to open the Sidebar.

Navigate to the Shaders tab.

Setup: Choose a Library Folder on your computer where your shaders will be stored.

Save: Select an object with an active material, type a name in the text box, and click Save as JSON or Pack as ZIP.

Organize: Use the Create Category tool to make subfolders for better organization.

Apply: Select a category, pick a shader from the dropdown, and click Apply Shader to assign it to the active object.
